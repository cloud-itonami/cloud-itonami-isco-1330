# Daily operations

1. Review facility, power, cooling, network, GPU/ECC, storage and security alerts.
2. Reconcile active jobs and tenant allocation with scheduler state; do not inspect tenant payloads.
3. Record energy and metered compute using immutable source timestamps and meter IDs.
4. Check capacity headroom, failed components, firmware advisories and expiring certificates/warranties.
5. Open incidents for threshold breaches. Observation is automatic; remediation follows the change or incident runbook.
6. Shift handoff records open incidents, changes, capacity risks and named owner. Never close an alert without evidence.
