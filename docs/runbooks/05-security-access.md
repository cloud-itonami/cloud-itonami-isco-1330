# Security and access

Identity must be individual, MFA-protected, least-privileged, time-bounded and
ticket-linked. Privileged and physical access requires approval; shared default
credentials are prohibited. Log access grants, use and revocation.

Review privileged access monthly and on role change. Rotate secrets after
suspected exposure and preserve evidence. Visitor access requires identity,
sponsor, purpose, entry/exit time and escort. Removable media follows
`[SITE-SPECIFIC MEDIA CONTROL]`.
